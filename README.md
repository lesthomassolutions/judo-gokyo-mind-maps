# Judo Gokyo no Waza Mind Maps

Interactive mind maps of the 40 original Kodokan throws (Gokyo no Waza), organized by the eight directions of off-balance (Happo no Kuzushi), from a classic right-sided perspective. Each technique page shows the direction of attack and combination options if the first attack fails.
